# cli

This folder contains three simple Python programs:

- `calculator.py` - a command-line calculator
- `expense_tracker.py` - a small expense tracking app
- `program.py` - a sample Python program

## Run the programs

Open a terminal in this folder and use Python 3.

### 1) Run the calculator

```bash
python3 calculator.py
```

### 2) Run the expense tracker

```bash
python3 expense_tracker.py
```

### 3) Run the sample program

```bash
python3 program.py
```

## Notes

- If `python3` does not work on your machine, try:

```bash
python calculator.py
```

- Make sure you are in the same folder as the files before running them.

```bash
cd /home/student/cli
```

## Example

```bash
cd /home/student/cli
```
